🚑 Smart Emergency Route Finder

Shortest road route to a hospital using Dijkstra’s algorithm on a simulated city. DAA mini-project, academic prototype.

Distance is shortest road length in km, not travel time. Traffic and hospital availability are not considered.

Each row = one place taken from the priority queue (smallest distance first). “Updates” are the roads relaxed: a shorter distance was found.

📘 Algorithm in 5 steps
    
  
  1. Source distance = 0; every other place = ∞.
    2. 
  
  2. Take the unvisited place with the smallest distance (priority queue).
    3. 
  
  3. Relax its roads: if dist[u] + km < dist[v], update dist[v] and prev[v] = u.
    4. 
  
  4. Repeat until the queue is empty.
    5. 
  
  5. Rebuild the route by following prev from destination back to source.

 
⏱ Analysis
    
  
  • Graph: adjacency list (sparse road network, O(V+E) memory).
    • 
  
  • Time: O((V+E) log V) with a binary heap. Space: O(V+E).
    • 
  
  • Needs non-negative weights, because the greedy choice assumes distances never shrink later.
    • 
  
  • Limits: no traffic, closures, or hospital capacity. Fictional data.
